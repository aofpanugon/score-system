# ระบบเก็บคะแนนและส่งงานออนไลน์

ระบบสำหรับครูและนักเรียน: นักเรียนดูคะแนน ดูงานค้างและส่งงาน ครูจัดการรายวิชา ตรวจงาน ลงคะแนนเก็บ กลางภาค ปลายภาค ส่วนแอดมินจัดการสมาชิก ภาพหน้าปก และการตั้งค่าระบบ

```
หน้าเว็บ (GitHub Pages) ──fetch──▶ Google Apps Script (API) ──▶ Google Sheet (ข้อมูล) + Google Drive (ไฟล์งาน)
   index.html + config.js           apps-script/Code.gs
```

ใช้งานฟรีทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์ ข้อมูลอยู่ใน Google บัญชีของคุณเอง

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (นักเรียน / ครู / แอดมิน) |
| `config.js` | ใส่ URL ของ API (ไฟล์เดียวที่ต้องแก้) |
| `apps-script/Code.gs` | ฝั่งเซิร์ฟเวอร์ครบทุกฟังก์ชัน + `setup()` + `seedDemo()` |
| `apps-script/appsscript.json` | ตั้งค่า Apps Script (เขตเวลา ไทย, V8, สิทธิ์ Web App) |
| `.github/workflows/pages.yml` | เผยแพร่หน้าเว็บขึ้น GitHub Pages อัตโนมัติเมื่อ push |
| `.github/workflows/test.yml` | รันชุดทดสอบตรรกะ API อัตโนมัติ |
| `tests/` | ชุดทดสอบ (จำลอง Apps Script ในเครื่อง) `npm test` |

## ติดตั้ง (ประมาณ 10 นาที)

### ขั้นที่ 1 — ติดตั้งฝั่งเซิร์ฟเวอร์บน Google

1. สร้าง **Google Sheet ใหม่** (ตั้งชื่ออะไรก็ได้)
2. เมนู **ส่วนขยาย → Apps Script** แล้วลบโค้ดเดิม วางเนื้อหาของ `apps-script/Code.gs` ทั้งไฟล์
   (ถ้าต้องการตั้งเขตเวลา: ไอคอนฟันเฟือง *การตั้งค่าโปรเจ็กต์* → ติ๊ก *แสดงไฟล์ appsscript.json* แล้ววางเนื้อหาจาก `apps-script/appsscript.json`)
3. เลือกฟังก์ชัน **`setup`** แล้วกด **เรียกใช้** อนุญาตสิทธิ์ครั้งแรก (Sheet / Drive)
   ระบบจะสร้างชีตทั้งหมด โฟลเดอร์เก็บไฟล์งานใน Drive และครูตัวอย่างรหัส `T001`
4. (ไม่บังคับ) เรียกใช้ **`seedDemo`** เพื่อสร้างนักเรียน 02900–02902 วิชา และงานตัวอย่างไว้ลอง
5. **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   แล้วคัดลอก **URL ที่ลงท้ายด้วย `/exec`**

> ทุกครั้งที่แก้ `Code.gs` ต้อง **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL เดิมจึงจะใช้โค้ดใหม่

### ขั้นที่ 2 — เผยแพร่หน้าเว็บบน GitHub

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมด (หรือ `git push`) ไปที่สาขา `main`
2. แก้ `config.js` ใส่ URL จากขั้นที่ 1:
   ```js
   window.APP_CONFIG = {
     API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'
   };
   ```
3. ที่ repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**
4. Push อีกครั้ง (หรือแท็บ **Actions → Deploy to GitHub Pages → Run workflow**) รอ 1–2 นาที
   เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

ถ้าเว้น `API_URL` ว่างไว้ หน้าเว็บจะเปิดในโหมดตัวอย่าง (ข้อมูลจำลอง ไม่บันทึกจริง) เหมาะสำหรับดูหน้าตา

## เริ่มใช้งานครั้งแรก

| ผู้ใช้ | เข้าสู่ระบบ | PIN เริ่มต้น |
|---|---|---|
| แอดมิน | เมนู *แอดมิน* | `123456` |
| ครู | เมนู *ครูผู้สอน* กรอกรหัสครู (เช่น `T001`) + PIN | `123456` |

**ให้เปลี่ยน PIN ทันที** — แอดมิน: แท็บ *ตั้งค่าระบบ*, ครู: แท็บ *เปลี่ยน PIN*
(PIN เป็นตัวเลข 6 หลัก ถ้ากรอกผิดครบ 5 ครั้งจะถูกล็อก 15 นาที)

ลำดับการตั้งค่าที่แนะนำ:
1. **แอดมิน** ตั้งชื่อระบบ คำโปรย โลโก้ ภาพหน้าปก และเพิ่มครูกับนักเรียน (ครูใหม่ได้ PIN `123456`, ปุ่ม *รีเซ็ต PIN* คืนค่าให้ได้)
2. **ครู** เพิ่มรายวิชาของตนเอง → เพิ่มนักเรียนเข้าวิชา (ด้วยรหัส 5 หลัก หรือนำเข้า CSV) → มอบหมายงาน
3. **นักเรียน** กรอกรหัส 5 หลักเพื่อดูคะแนน / ค้นหางานค้างแล้วส่งงาน

## ระบบคะแนน

คะแนนรวมเต็ม 100 = **ใบงาน** + **คะแนนเก็บ** + **ทดสอบ** + **กลางภาค** + **ปลายภาค**

- ใบงาน / ทดสอบ: นักเรียนส่งไฟล์ ครูตรวจแล้วให้คะแนน
- **คะแนนเก็บ**: ครูลงคะแนนได้ทันทีโดยไม่ต้องส่งไฟล์ (ปุ่ม *ลงคะแนน*)
- กลางภาค / ปลายภาค: ครูกรอกในสมุดคะแนน
- เกรด: ≥80=4, ≥75=3.5, ≥70=3, ≥65=2.5, ≥60=2, ≥55=1.5, ≥50=1, ต่ำกว่า=0 (เกรดพิเศษ ขร. 0 สม. มผ. ผ. แทนที่เกรดคำนวณ)

## สิทธิ์การใช้งาน

- **นักเรียน** ดูเฉพาะข้อมูลของตนเองด้วยรหัส 5 หลัก และส่งงานได้เฉพาะวิชาที่ลงทะเบียน
- **ครู** เห็น/แก้ไข/ลบได้เฉพาะรายวิชาของตนเอง เปลี่ยนได้เฉพาะ PIN ของตนเอง (ตั้งค่าระบบไม่ได้)
- **แอดมิน** จัดการสมาชิกทั้งหมด ภาพหน้าปก และตั้งค่าระบบ

## ข้อควรรู้เรื่องความปลอดภัยและข้อจำกัด

- นักเรียนเข้าด้วยรหัส 5 หลักโดยไม่มีรหัสผ่าน ใครรู้รหัสก็ดูคะแนนได้ — เหมาะกับการใช้ในห้องเรียน หากต้องการเข้มงวดกว่านี้ควรเพิ่มรหัสผ่านนักเรียน
- ไฟล์งานตั้งค่า "ผู้ที่มีลิงก์ดูได้" เพื่อให้ครูทุกคนเปิดดูได้ ลิงก์เดาไม่ได้แต่ไม่ได้ปิดสนิท
- ไม่รับไฟล์ที่เป็นโปรแกรม (.exe .bat .js ฯลฯ) ส่งได้สูงสุด 5 ไฟล์ รวมไม่เกิน 25 MB
- Apps Script มีโควตารายวัน (ดู Google ว่าด้วย quotas) ถ้าใช้พร้อมกันจำนวนมากอาจช้าลง
- ทุกคนที่มี URL ของ API เรียกใช้ได้ แต่ฟังก์ชันของครู/แอดมินต้องใช้ PIN และมีการล็อกเมื่อเดาผิดซ้ำ
- PIN เก็บเป็นค่าแฮชพร้อม salt ใน Sheet เจ้าของ Sheet ควรแชร์ให้เฉพาะผู้ดูแลที่ไว้ใจ

## พัฒนาและทดสอบในเครื่อง

```bash
npm test      # ชุดทดสอบตรรกะ API (ไม่ต้องใช้บัญชี Google)
npm run dev   # เปิดเว็บจำลอง http://localhost:8799 พร้อม API จำลองและข้อมูลตัวอย่าง
```

ชุดทดสอบจำลอง SpreadsheetApp / DriveApp ฯลฯ ให้ครอบคลุมตรรกะ แต่ไม่ใช่การทดสอบกับ Google จริง ควรลองทำตามขั้นตอนติดตั้งและใช้ `seedDemo()` ตรวจสอบหนึ่งรอบก่อนใช้งานจริง
